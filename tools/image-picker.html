Image picker

Local dev tool, not part of the site. Pick an aesthetic, try out search phrases, and see the exact Wikimedia Commons photos the real result page would use - same AQ.images.searchTerm(), same rejection rules. Pin the ones that actually fit; a curated photo always wins over a live-search guess. Everything you pin lives in one file, data/images.json, grouped the same way data/playlists.json groups videos.
